Desktop Buddy flasher

Turn a cheap ESP32 touch display into a desk companion for the Claude desktop app: it shows what your sessions are doing, lets you approve or deny tool requests with a tap, and keeps a small pet that reacts to your work. Pick your board below and install the firmware from this page — no toolchain needed.

You need: Chrome or Edge on a desktop computer (Web Serial), and a USB data cable. Installing erases whatever the board ran before.

After installing

  1. Resistive-touch boards start with a touch calibration: tap each corner marker as it appears.
  2. In the Claude desktop app: Help → Troubleshooting → Enable Developer Mode.
  3. Then Developer → Open Hardware Buddy…, click Connect and pick Claude-XXXX (the board's name on its Info → Bluetooth page).
  4. Hold the left side of the screen for about half a second to open the menu. Settings → rotation turns the screen; the board restarts in the new orientation.

Troubleshooting

  • No port shows up: try another cable (many only carry power), or install the CH340 USB driver on older systems.
  • Native-USB boards (Elecrow Advance 3.5") that won't connect: hold BOOT, tap RESET, release BOOT, then retry.
  • Boards marked not yet tested build from the same code but haven't been run on real hardware yet — reports welcome on GitHub.
